- Responsive home, about, projects, and contact pages
- Mobile navigation
- Project cards with category filters
- Contact form that opens a prefilled email draft in the visitor’s email app
- Custom CSS illustrations and dark visual theme

## Run Locally

No build tools or package installation are required.

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a browser. You can also use the VS Code **Live Server** extension to run it locally.
